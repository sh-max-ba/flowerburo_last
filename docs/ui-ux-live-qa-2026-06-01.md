## 2. Дефекты, найденные в QA

### Исправлено в этой сессии
- **🔴 Сырые значения enum в `Select`** — на кассе способ оплаты показывался как `cash`, скидка как `none`; в фильтрах клиентов `__all__`/`recent`; в актах `all`/`all`; в доплатах готовых заказов. Причина: `base-ui` `<SelectValue>` без функции-рендера показывает «сырое» значение (а не подпись), и это проявляется там, где `value ≠ label`. На карточке сделки было сделано правильно (`<SelectValue>{(value) => label(value)}</SelectValue>`). **Исправлено** во всех `Select`: касса (оплата/скидка/получение/источник ×6), клиенты (источник/сортировка ×3), акты (тип/статус ×2), готовые заказы (оплата ×2).

### Открытые (кандидаты в работу)
- **🟠 Топбар тесный на планшете (768)** — статус смены + «Детали смены» + «Закрыть смену» съедают ширину, заголовок обрезается до «Кас…»/«Сд…». Нужно свернуть управление сменой в компактное меню на узких экранах.
- **🟠 Раздел «Пользователи» оторван от навигации** — нет пункта в сайдбаре; на `/users` подсвечивается «Настройки»; попасть можно только по прямой ссылке. → добавить пункт в «Администрирование» или вкладкой в «Настройки».
- **🟡 Карточка сделки на десктопе** — левая колонка чата Wazzup занимает ~50% даже когда интеграция выключена (видно «Wazzup отключён»), а форма зажата в ~40%. Полупустой экран. → когда чат выключен, форму — на всю ширину.
- **🟡 Дубль заголовка на «Букетах»** — под топбаром «Букеты» ещё один in-page заголовок «Букеты / Шаблоны…». В других модулях такого нет. → убрать in-page header.
- **🟡 Сортировка `default`** — на «Стол заказов»/«Готовые» контрол сортировки показывает значение `default` (нерусское). → русские подписи опций сортировки.

## 3. План «удобный интерфейс» (упрощение, дашборд, перестановка)

Принцип: каждый модуль должен решать ОДНУ задачу, а всё «обзорное/что требует внимания» — вынести в дашборд. Убрать дубли, сократить длинные панели, держать главное действие на виду.

### 3.1. Новый «Дашборд» (главная для owner/manager) — L
Сейчас owner попадает на «Касса». Предлагается отдельный экран-сводка, который собирает то, что сейчас разбросано по модулям и требует обхода:
- **Смена**: статус (открыта/закрыта), ожидается в кассе, ответственный (сейчас живёт в топбаре).
- **Выручка за сегодня** + число продаж.
- **Требует дозаказа**: число позиций «Мало ≤3» и «В минусе» со ссылкой в отфильтрованный `/stock` (сейчас надо открыть склад и смотреть).
- **Сделки**: входящие / требуют действия (есть бейдж, но только в сайдбаре).
- **Заказы**: готовые к выдаче / просроченные.
- **Долги клиентов**: суммарный открытый остаток.
Эффект: модули сбрасывают «обзорные» блоки и фокусируются на работе; «что горит» — в одном месте. Флорист остаётся на `/orders` (задача), owner/manager → `/dashboard`. Требует решения по составу KPI.

### 3.2. Перестановка / удаление / упрощение по модулям
- **Касса (right-панель длинная)** — `S/M`:
  - «Скидка на чек» свернуть по умолчанию за «+ Скидка» (большинство чеков без скидки).
  - «Комментарий» опустить/свернуть.
  - Вертикальный поток: Итого → Способ оплаты → Получено → **Сдача** → Провести.
  - **Sticky-футер** с «Итого / Сдача / Провести продажу», чтобы главное действие было видно без прокрутки длинной панели.
- **Карточка сделки** — `M`: при выключенном Wazzup — форма на всю ширину (убрать пустую колонку чата); при включённом — текущий сплит.
- **Топбар** — `S/M`: на узких экранах «Детали смены»/«Закрыть смену» в выпадающее меню «⋯», бейдж статуса компактный; заголовок не обрезать.
- **Букеты** — `S`: убрать дублирующий in-page заголовок.
- **Настройки/Пользователи** — `S`: «Пользователи» — вкладкой «Доступ» в Настройки (или пункт в «Администрирование»); чинит и навигацию, и активный пункт сайдбара.
- **Стол заказов/Готовые** — `S`: русские подписи сортировки; сорт + «Список/Календарь» в один компактный тулбар.
- **Склад** — `S`: вид «Требует дозаказа» (Мало+Минус) как быстрый пресет; чипы уже есть.
