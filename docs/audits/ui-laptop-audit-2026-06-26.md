Цель: улучшить общий UI/UX FlowerBuro на ноутбучных экранах (13–15″, ширина 1280–1440px,
высота 720–900px — после хрома браузера ≈600–780px полезной высоты; при открытом сайдбаре
16rem контент ≈1040–1180px). Прод; правки только аддитивные, с responsive-префиксами, обратимые.

Метод: многоагентный аудит (6 кластеров UI + синтез). Всего **68 находок**.
Полный машинный вывод сохранён в транскрипте воркфлоу `laptop-ui-audit` (run wf_7a8eff23-bab).

## Вердикт

На ноутбуке интерфейс читается как «планшетный UI, растянутый вверх»: щедрые `gap-5/gap-6`,
заголовок страницы `text-2xl`, дублирующий заголовок в топбаре, дефолтный паддинг карточек
`py-4`, и несколько таблиц с жёстким `min-w-[900…1120px]`, которые заставляют скроллить по
горизонтали внутри ~1040px контента.

Главный рычаг — общий контейнер контента (`crm-shell.tsx:176`) + общие примитивы
`Card`/`PageHeader`/`Dialog`: их подтяжка уплотняет сразу все экраны. Второй рычаг — ревизия
фиксированных `min-w` у таблиц, чтобы плотные таблицы перестали скроллиться.

## Ключевые темы

1. **Слишком много вертикального воздуха** — `gap-5/6`, паддинги стакаются и выталкивают
   фильтры/футеры/кнопки за пределы экрана на высоте ~620–700px.
2. **Таблицы переполняются по горизонтали** внутри ~1040px (`min-w-[960/1120/900]`, 8-колоночные
   сводки, таблицы без ширин колонок). Русские заголовки (~+15% ширины) ускоряют переполнение.
3. **Контент искусственно сужен** — `max-w-[1600px]`, `xl:max-w-4xl` и т.п. оставляют 200–280px
   пустых полей по краям на ноутбуке.
4. **Шиты/диалоги не настроены под ноутбук** — `Sheet` по умолчанию `w-3/4`, `Dialog max-h-[90vh]`
   с уезжающим футером.
5. **Сетки прыгают 1→2/3 колонки на `lg`** и выглядят разреженно в полосе 1024–1280px.
6. **Мелкий/тусклый текст на ключевых данных** — `text-xs` на суммах/статусах, обрезка имён без тултипа.

## План по пачкам (низкий риск → выше)

- **Пачка 1 — глобальная плотность каркаса (макс. рычаг, мин. риск).** ✅ Внедрено локально 2026-06-26
  (не задеплоено): `crm-shell.tsx` `gap-5`→`gap-4 2xl:gap-5`; `page-header.tsx` `text-2xl`→`text-xl 2xl:text-2xl`;
  `dialog.tsx` `max-h-[90vh]`→`max-h-[calc(100dvh-4rem)]`.
  Из пачки **сознательно исключены** правка `Card`-паддинга (взаимодействие с `data-[size=sm]` +

  перенесены в верифицируемую пачку.
