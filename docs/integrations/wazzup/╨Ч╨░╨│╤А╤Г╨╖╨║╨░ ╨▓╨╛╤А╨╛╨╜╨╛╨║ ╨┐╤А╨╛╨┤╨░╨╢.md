Загрузка воронок продаж

Когда пишет клиент, которого нет в CRM, создается сделка. В интерфейсе Wazzup нужно настроить, в какой воронке будет создаваться сделка. Чтобы загрузить в Wazzup или обновить воронки продаж с этапами, вызовите:

 POST  https://api.wazzup24.com/v3/pipelines

Параметры запроса
Параметр 	Тип 	Описание
id 	Any 	ID воронки, не более 100 символов
name 	String 	Название воронки, которое будет отображаться в настройках интеграции. Не более 100 символов
stages 	Object 	Массив с этапами воронки. Если в CRM нет этапов, но есть несколько воронок, параметр stages не нужен. Если stages есть, но не заполнен, возникнет ошибка
stages.id 	String 	Идентификатор этапа воронки. Не более 100 символов
stages.name 	String 	Название этапа воронки. Не более 100 символов
Пример запроса

fetch("https://api.wazzup24.com/v3/pipelines", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "Authorization": "Bearer {apiKey}",
  },
  body: [
    {
      id: "string-id",
      name: "Зарегистрировались"
      stages: [
        {
          id: "1"
          name: "Подключили тестовый период"
        },
        ...
      ]
    },
    ...
  ]
});

Получение списка загруженных воронок

Для получения списка загруженных воронок необходимо вызвать:

 GET  https://api.wazzup24.com/v3/pipelines

Пример ответа

HTTP/1.1 200 OK
[
  {
     id: "string-id",
     name: "Зарегистрировались"
     stages: [
       {
         id: "1"
         name: "Тестовый период"
       },
       ...
     ]
   },
   ...
]
