Миграция пользователей API v2 на API v3

Клиентов, которые используют интеграцию версии API v2, необходимо перевести на новую версию — API v3.

Основные шаги миграции:

1. Нужно создать работающую интеграцию на API v3 и опубликовать ее в маркетплейсе Wazzup.

2. По готовности к миграции переключить вебхуки с API v2 на API v3. Для этого вызовите: POST https://api.wazzup24.com/v3/migration

3. Начать использовать для выбранных пользователей методы API v3, вместо методов API v2. Для авторизации нужен тот же API ключ клиента, который использовали для запросов в API v2.
Метод переключения вебхуков API v2 на v3

Чтобы у конкретного клиента переключить вебхуки с API v2 на API v3, необходимо вызвать:

 POST https://api.wazzup24.com/v3/migration

В заголовке необходимо передать API ключ партнера. В теле запроса должен быть JSON с параметрами:
Параметр 	Тип 	Описание
clientApiKey 	String 	API ключ клиента, который использовали для отправки запросов API v2
webhooksUri 	String 	URL, на который будут приходить вебхуки
subscriptions 	Object 	Объект с подписками на два типа вебхуков. Отсутствие аналогично False
subscriptions.messagesAndStatuses 	Boolean 	Подписка на вебхуки о сообщениях и их статусах
subscriptions.contactsAndDealsCreation 	Boolean 	Подписка на вебхуки о создании сущностей
За один запрос можно мигрировать только одного клиента. Если у вас несколько клиентов, нужно сделать запрос для каждого.
