Общие ошибки

429 Too Many Requests. Лимит — не более 500 запросов каждые 5 секунд. Счетчик сбрасывается каждые 5 секунд, после чего можно отправлять новые запросы.

401 Unauthorized. Не передали ключ API или передали неправильный ключ.

500 Internal server error

403 Forbidden: Запросы на роуты, неразрешенные к использованию с sidecar API KEY, могут приводить к ошибкам TOO_MANY_ENTITIES. 

У роутов:

    POST /contacts,
    POST/users,
    POST /deals,
    PATCH /contacts/bulk_delete,
    PATCH /deals/bulk_delete

есть ограничение на количество присланных для обработки сущностей: 100 штук за один раз.
Формат

Когда возникает ошибка, вернется код статуса 4ХХ, а тело ответа будет либо пустым, либо будет содержать JSON вида:

{
error: 'КОД_ОШИБКИ',
description: 'CHANNEL_BLOCKED', // краткое описание ошибки на английском
[data]: {} // объект с дополнительной информацией. Не обязателен. Предназначен для анализа разработчиками с целью выявления причины ошибки.
}
