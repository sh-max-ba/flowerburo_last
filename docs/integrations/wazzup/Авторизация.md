Авторизация

Для авторизации необходим ключ API. Его можно получить следующим образом:

1. Если вы еще не подключили канал, добавьте его в разделе «Каналы».

2. Перейдите в раздел «Интеграция с CRM».

3. Выберите API → Подключить.

4. Скопируйте ключ API. После подключения интеграции, ключ можно найти в том же разделе «Интеграция с CRM» → вкладка «Дополнительно».

Чтобы применить ключ, указывайте его как значение заголовка следующем виде:

 Authorization: Bearer 33a817cbc1504bd5885574d8f0290cd3
